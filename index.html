Decoradores

Funciones que modifican funciones

✅ ▼
import time def cronometro(func): def wrapper(*args, **kwargs): inicio = time.time() resultado = func(*args, **kwargs) fin = time.time() print(f"{func.__name__} tardó {fin-inicio:.4f}s") return resultado return wrapper @cronometro # ← decorador def proceso_pesado(): time.sleep(1) return "listo"
Avanzado

Generadores

yield — grandes datos sin explotar la RAM

✅ ▼

Un generador produce valores uno a la vez, no carga todo en RAM. Ideal para millones de registros.

# Sin generador: carga TODO en RAM def millones_lista(): return [x**2 for x in range(1_000_000)] # Con generador: produce de a uno ✅ def millones_gen(): for x in range(1_000_000): yield x**2 # Generator expression cuadrados = (x**2 for x in range(10))

Asincronía (asyncio)

async/await — tareas concurrentes

✅ ▼
import asyncio async def descargar(url: str): print(f"Descargando {url}...") await asyncio.sleep(1) # simula I/O return f"Datos de {url}" async def main(): # Ejecuta en PARALELO (no secuencial) resultados = await asyncio.gather( descargar("api.com/1"), descargar("api.com/2"), ) asyncio.run(main())
Avanzado

Arquitectura Interna

GIL, Bytecode, PVM, Garbage Collector

✅ ▼

🔄 Bytecode + PVM

Python compila a bytecode (.pyc) que ejecuta la Python Virtual Machine — no va directo a código máquina como C++.

🗑️ Garbage Collector

Usa conteo de referencias. Cuando un objeto tiene 0 referencias, se libera automáticamente de la RAM.

🔒 GIL (Global Interpreter Lock)

Solo un hilo ejecuta bytecode a la vez. Garantiza seguridad de datos pero limita el verdadero paralelismo de hilos.
